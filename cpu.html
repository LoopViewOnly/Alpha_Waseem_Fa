CPU

the primary hardware component that runs your operating system and applications by fetching, decoding, and executing program instructions.




Key Performance Terms

• Cores: Independent mini-processors inside a single CPU that let the computer handle multiple tasks at the same time. • Clock Speed (GHz): How fast a CPU completes cycles, measured in gigahertz. • Manufacturers: The two primary desktop and laptop CPU makers are Intel (known for Core i3/i5/i7/i9 series) and AMD known for the Ryzen series
